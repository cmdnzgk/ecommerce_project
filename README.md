# Django E-Commerce API Project

A simple e-commerce application built with Django and Django REST Framework.

## Features

- User authentication and authorization
- Product management
- Category management
- Shopping cart functionality
- REST API endpoints
- Product filtering by category
- Django ORM integration

## Technologies Used

- Python
- Django
- Django REST Framework
- SQLite
- Git
- GitHub

## Project Structure

- Products
- Categories
- Cart
- User Authentication
- API Endpoints

## Learning Goals

This project was developed to practice backend development concepts using Django and Django REST Framework.

The main focus areas were:

- REST API development
- Authentication and authorization
- Database operations using Django ORM
- Serializer usage
- Building scalable backend applications
